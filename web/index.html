How it works

AstroIdentify is a Python command-line tool. Give it a telescope image, with no coordinates or target name, and it works out where in the sky the image points, which catalogued objects are in the frame, and how well the image supports each identification.

  1. Load the image

    Reads JPEG, PNG or FITS files, keeps their metadata, and estimates the background and noise.

  2. Detect the stars

    Finds and measures point sources, with dedicated handling for saturated stars.

  3. Solve where it points

    Blind plate solving with a local Astrometry.net: only the pattern of detected stars is used, never a filename or target hint.

  4. Match Gaia DR3

    Pairs detected stars with Gaia DR3 and refines the image’s sky coordinates.

  5. Identify objects

    Lists the galaxies, nebulae and clusters that SIMBAD places in the frame, and annotates them on the image.

  6. Grade the evidence

    Gives each identification a rule-based support level, from strong to catalogue-only. These are explicit rules, not probabilities.

Inspect an object. Pick any identified object to get a display-only stretched view of where it lies, with its catalogue position, size when known, and nearby reference stars.

Run it

$ pip install -e .
$ cp astroidentify.example.toml my-image.toml
$ astroidentify run my-image.toml

Needs Python 3.11+, a local Astrometry.net installation with index files, and network access (or a local cache) for the Gaia and SIMBAD queries. The project README has the full details.
